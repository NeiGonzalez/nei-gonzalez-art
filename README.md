# Nei González art

Proyecto React + Vite de la web de Nei González.

## Ejecutar en local

```bash
npm install
npm run dev
```

Abrir la dirección local indicada por Vite.

## Estructura de contenido

- `src/data/works.js`: fuente única de datos de las obras.
- `src/data/siteContent.js`: contenido general de Home, Services y columnas visuales.
- `public/assets/home/hero/`: imágenes del Hero.
- `public/assets/about/work-details/`: detalles de obras para las columnas dinámicas.
- `public/assets/about/exhibitions/`: imágenes de exposiciones para la columna central.
- `public/assets/logo-nei-gonzalez-art.png`: logo definitivo.
- `public/favicon.svg`: favicon NGa.

Los originales de las fotografías deben conservarse fuera de las versiones optimizadas para la web.
